# 🎬 CineMatch v2: AI-Powered Recommendation System

CineMatch is a high-performance recommendation engine that suggests movies and TV shows based on content similarity. It leverages Machine Learning to analyze metadata and provides a visually rich experience by fetching posters in real-time.

##  Features
- **Hybrid Search:** Search across 170k+ movies and TV series.
- **ML Driven:** Uses `CountVectorizer` and `Cosine Similarity` for precise recommendations.
- **Dynamic UI:** Built with Streamlit for a smooth and responsive user experience.
- **TMDB Integration:** Fetches live movie posters and metadata via API.
- **Memory Efficient:** Optimized to handle large datasets without high RAM consumption.

##  Tech Stack
- **Language:** Python
- **Libraries:** Pandas, Scikit-Learn, Requests
- **Frontend:** Streamlit
- **API:** The Movie Database (TMDB)
- **Environment:** Dotenv for secure API key management
